# Agent Context Entry Point

This folder contains repository-local context for future coding agents working on the public `0x2c.dev` blog frontend.

Read these files before changing code:

- `../AGENTS.md`: required top-level instructions for this repository.
- `.agents/project-context.md`: current frontend architecture, API assumptions, UX rules, and implementation conventions.
- `.agents/history.md`: summary of prior iterations derived from git history.
- `.agents/skills/commit/SKILL.md`: commit workflow skill, used only when the user asks to commit.

The sibling backend is `../blog-backend`. Before changing frontend API assumptions, inspect the backend source and docs, especially `../blog-backend/README.md` and `../blog-backend/docs/architecture/`.
